# The Anime Character &amp; Prompt Generator!
What it does for you: It will allow the user (as in you or me) to generate an female character complete with full info regarding their age, height, body type, name, birthday, zodiac sign, skin tone, hair, eyes, the outfit (which would be a two-toned one-piece racerback competition swimsuit), and the location, and it produces an AI prompt, seed, and negative prompt to use in your favorite text-to-image generators like Perchance, SDXL, Automatic1111, ComfyUI, etc. via the Ctrl + C (on the program) and Ctrl + V (on the text-to-image generator of your choice). Plus, with the checkbox toggle, you can choose to have not-safe-for-work prompts or not (it'll be for all ages by default). The character will be generated from a click of the green Generate Character button.

The character_gen.py file is the source code for the program that is character_gen.exe. Note: The Python source code would be bundled executable file via a ZIP file in either GitHub download methods, Google Drive users would only get the executable file as the file works without the source Python script. It was made in Python and compiled with PyInstaller (which allows Python scripts to become programs).
